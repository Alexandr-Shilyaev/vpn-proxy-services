# VLESS + Reality (backend) — план

Базовый (обязательный) протокол проекта: **VLESS + Reality** на Xray. Основной канал.

Статус: **не реализован**, заготовка под будущую разработку.

Чтобы бот подхватил протокол, здесь должны появиться скрипты с общим контрактом
(см. [корневой README](../README.md#контракт-backendа-как-добавить-протокол)):

- `install_server.sh` — установка Xray, генерация ключей Reality, базовый конфиг;
- `add_user.sh <имя>` — добавляет UUID/клиента, печатает `CONF=<путь> QR=<путь>`
  (для VLESS обычно это ссылка `vless://…`, из неё же делается QR);
- `del_user.sh <имя>` — удаляет клиента, печатает `DELETED=<имя>`;
- `list_users.sh` — список клиентов.

После этого добавить запись в `PROTOCOLS` в `../bot/bot.py`.
