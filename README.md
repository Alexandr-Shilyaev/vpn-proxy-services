# vpn-proxy-services

Self-hosted VPN/прокси-сервер с управлением через **один общий Telegram-бот**: смотреть
пользователей, добавлять и удалять их, получать конфиги и QR — без захода на сервер.

Бот построен по принципу «один бот → несколько протоколов». Каждый протокол — отдельный
backend (подпапка с одинаковым набором скриптов), бот добавляет его в меню автоматически.

## Роадмап протоколов

| Приоритет | Протокол | Когда | Статус |
|-----------|----------|-------|--------|
| База (обязательно) | **VLESS + Reality** (Xray) | основной канал | план |
| Резерв №1 (простота) | **AmneziaWG** | WireGuard с обфускацией, обход DPI | реализован |
| Резерв №2 (плохая сеть, UDP лучше TCP) | **Hysteria 2** | когда TCP режут / большие потери | план |

Сейчас реализован только **AmneziaWG**. Остальные добавляются как новые подпапки
(`vless-reality/`, `hysteria2/`) с тем же контрактом скриптов — бот их подхватит.

## Структура

```
vpn-proxy-services/
├── setup.sh              # единый bootstrap: ставит протоколы + общий бот
├── bot/                  # ОДИН Telegram-бот на все протоколы
│   ├── bot.py            # реестр PROTOCOLS (сейчас только amneziawg)
│   ├── requirements.txt
│   └── config.env.example
├── amneziawg/            # backend AmneziaWG (реализован)
│   ├── install_server.sh # установка сервера протокола
│   ├── add_user.sh       # добавить клиента -> печатает CONF=… QR=…
│   ├── del_user.sh       # удалить клиента   -> печатает DELETED=…
│   ├── list_users.sh     # список клиентов
│   └── lib/common.sh
├── vless-reality/        # backend (план, База)
└── hysteria2/            # backend (план, Резерв №2)
```

## Быстрый старт (в две команды)

На свежем VPS (Ubuntu 22.04/24.04):

```bash
git clone <ваш-репозиторий> vpn-proxy-services && cd vpn-proxy-services
sudo ./setup.sh --token <BOT_TOKEN> --admins <ваш_telegram_id>
```

По умолчанию ставится протокол `amneziawg` и общий бот. Затем отправьте боту `/start`:
он покажет список протоколов → меню (добавить / удалить / список) → пришлёт QR и `.conf`.

Опции:

```bash
# выбрать протоколы (по мере реализации) и сетевые параметры
sudo ./setup.sh --token XXX --admins 12345 --protocols amneziawg --port 51820 --ip 203.0.113.10

# сетевые параметры AmneziaWG: MTU, IPv6, DNS (пробрасываются в install_server.sh)
sudo ./setup.sh --token XXX --admins 12345 --mtu 1280 --ipv6 auto --dns 1.1.1.1,1.0.0.1

# только серверы протоколов, без бота
sudo ./setup.sh --no-bot
```

По умолчанию AmneziaWG ставится в формате **2.0** (имитация протокола); для старых клиентов
добавьте `--legacy`. Сетевые опции (`--mtu`, `--subnet6`, `--ipv6 auto|on|off`, `--legacy`,
`--port`, `--subnet`, `--dns`, `--ip`, `--iface`) пробрасываются в установщик протокола —
подробности в [`amneziawg/README.md`](amneziawg/README.md).

Токен/админов можно не передавать флагами — скрипт спросит интерактивно.

## Контракт backend'а (как добавить протокол)

Чтобы бот подхватил новый протокол, в его подпапке нужны три скрипта с единым интерфейсом:

- `add_user.sh <имя>` — создаёт клиента и печатает строку `CONF=<путь> QR=<путь>`;
- `del_user.sh <имя>` — удаляет клиента и печатает `DELETED=<имя>`;
- `list_users.sh` — печатает таблицу (первый столбец — имя) или `Клиентов пока нет.`;
- клиенты хранятся в каталоге, указанном в реестре `PROTOCOLS` (`clients_dir`).

После этого добавьте запись в `PROTOCOLS` в [`bot/bot.py`](bot/bot.py) — и протокол
появится в меню бота.

## Безопасность

- `bot.env` и каталоги состояния держите с правами `600/700` — там токен и приватные ключи.
- Управление ботом строго по белому списку `ADMIN_IDS`.
- Имена клиентов валидируются (`A-Z a-z 0-9 _ -`), посторонний ввод в shell не попадает.

Подробности по AmneziaWG — в [`amneziawg/README.md`](amneziawg/README.md).
